# PortfolioX v2

PortfolioX is a **multi-platform investment portfolio monitoring and analytics frontend**. It is intentionally not a trading/broker application.

## What changed
- Login and signup flow (frontend demo auth)
- Light/dark theme toggle
- Stocks, ETFs, mutual funds, bonds and crypto
- Multi-platform statement import workflow: Groww, INDmoney, CoinSwitch, Zerodha, Upstox and Other
- Consolidated portfolio and transaction history
- Market-price monitoring UI and portfolio P/L calculations using mock current prices
- Analytics dashboard
- Data Structures page showing Linked List, Hash Table, BST, Sorting, Stack and Queue use cases
- API service layer ready for Spring Boot

## Run
```bash
npm install
npm run dev
```

## Important
`node_modules` is intentionally not included. It is generated by `npm install` from `package.json`.

The current frontend uses mock data. Real statement parsing and real market-price APIs should be implemented in the Spring Boot backend later.
